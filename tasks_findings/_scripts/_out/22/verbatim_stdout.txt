(0) Symbolic Roughgarden smoothness gap for the PEG
======================================================================
SW(s^opt)         = -A^{opt}_1*w_1 - A^{opt}_2*w_2 + 2*V(sigma_opt)
SW(s)             = -A^{s}_1*w_1 - A^{s}_2*w_2 + 2*V(sigma_s)
dev_sum LHS       = -A^{1d}_1*w_1 - A^{2d}_2*w_2 + V(sigma^{1d}) + V(sigma^{2d})
gap (RHS - LHS)   = A^{1d}_1*w_1 + A^{2d}_2*w_2 - A^{opt}_1*lambda*w_1 - A^{opt}_2*lambda*w_2 + A^{s}_1*mu*w_1 + A^{s}_2*mu*w_2 + 2*lambda*V(sigma_opt) - 2*mu*V(sigma_s) - V(sigma^{1d}) - V(sigma^{2d})

V-part (V-side of the gap):
   2*lambda*V(sigma_opt) - 2*mu*V(sigma_s) - V(sigma^{1d}) - V(sigma^{2d})
A-part (A-side of the gap):
   A^{1d}_1*w_1 + A^{2d}_2*w_2 - A^{opt}_1*lambda*w_1 - A^{opt}_2*lambda*w_2 + A^{s}_1*mu*w_1 + A^{s}_2*mu*w_2
(V-part + A-part - gap) = 0   (must be 0)

Interpretation.
  The V-part is negative iff
     V(sigma_d1) + V(sigma_d2)
       >= 2*lambda*V(sigma_opt) - 2*mu*V(sigma_s).
  Because V is monotone-decreasing and sigma_d_k <= sigma_s at every
  unilateral deviation to opt (increasing one player's eps drops sigma
  by lem:externality), V(sigma_d_k) >= V(sigma_s), so the V-part
  admits the (crude) sufficient condition
     2*V(sigma_s) >= 2*lambda*V(sigma_opt) - 2*mu*V(sigma_s)
     <=> V(sigma_s) * (1 + mu) >= lambda*V(sigma_opt).
  This is trivially satisfied when V(s) = V(opt) and mu >= lambda - 1.

  The A-part is negative iff
     w_1 * A^{1d}_1 + w_2 * A^{2d}_2
       <= lambda*(w_1 A^{opt}_1 + w_2 A^{opt}_2)
          - mu*(w_1 A^{s}_1 + w_2 A^{s}_2).
  This is the hard direction: A^{1d}_1 = A_1(opt_1, s_2), and
  when s_2 is small (adversarial coalition), the externality on
  player 1 makes A^{1d}_1 LARGE even though player 1 is playing opt_1.
  See Section 3 of the findings note for the analytic bound.
